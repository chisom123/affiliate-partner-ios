# Affiliate Partner iOS App

iOS app for affiliates to manage their referral campaigns, track earnings, and withdraw payouts.

---

## 📱 Overview

This app is the companion for the photo competition affiliate program. Affiliates can sign up, create custom referral links, share them on Instagram Stories, track their earnings in real-time, and withdraw payouts once they reach the minimum threshold.

---

## 🛠️ Tech Stack

- **Swift** – iOS frontend
- **Firebase** – Auth, Firestore, Storage
- **Wise / PayPal** – Payout processing

---

## ✨ Key Features

- **Affiliate signup** – Create an account and start earning immediately
- **Profile setup** – Add profile picture and name
- **Link management** – Create and share custom referral links
- **Earnings tracking** – Real-time balance and earnings history
- **Payout withdrawals** – Withdraw earnings once you hit the minimum threshold
- **Recruit tracking** – View recruits and their performance

---

## 🏗️ Architecture

Built on a **Firebase-first** backend:

- **Firestore** – Stores affiliate data, links, earnings, and recruits
- **Firebase Auth** – User authentication and session management
- **Cloud Storage** – Profile picture uploads

## ⚙️ Setup

This project uses Firebase. To run it locally:

1. Clone the repo  
2. Create a Firebase project and enable Auth, Firestore, and Storage  
3. Add your `GoogleService-Info.plist` to the project root  
4. Open in Xcode and build
